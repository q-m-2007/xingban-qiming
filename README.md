# 星伴·启明 CCG追问引擎（旧版备份）

> **状态：已归档** - 此版本已被 V3 统一教学管道替代

## 项目说明

这是星伴·启明的早期版本，基于 CCG（Cognitive Conflict Graph，认知冲突图谱）追问引擎。

## 替代版本

新版 V3 统一教学管道已部署：
- 仓库：https://github.com/q-m-2007/xingban-qiming.git
- 算法：融合13条铁律的七层架构
- 接口：`/api/v3/chat/message`
