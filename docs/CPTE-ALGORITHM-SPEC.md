## 一、核心创新

**CPTE（Cognitive Phase Transition Engine）** — 认知相变引擎

核心命题：学习不是知识的线性积累，而是认知能量景观中的相变过程。

正如水不会"逐渐"变成冰——它在临界温度处发生突变——学生的理解也不是渐进改善的。学生存在于亚稳态（误解）中，当跨越能量壁垒时才能跃迁到新的稳态（正确理解）。

**与 CCG 算法的本质区别**：
- CCG：图节点 + 规则检测（离散、静态）
- CPTE：能量景观 + 动力学演化（连续、动态、可预测）

## 二、数学基础

### 2.1 认知状态空间

学生在某个知识点上的认知状态用 N 维信念向量表示：

```
b(t) = [b₁(t), b₂(t), ..., bₙ(t)] ∈ [-1, 1]ⁿ
```

其中 bᵢ ∈ [-1, 1]，-1 表示完全错误，+1 表示完全正确，0 表示不确定。

### 2.2 认知能量景观（核心创新）

学生的认知状态存在于一个多维能量景观中。能量函数定义为：

```
E(b) = -Σᵢ hᵢ·bᵢ - Σᵢ<ⱼ Jᵢⱼ·bᵢ·bⱼ + Σₐ Dₐ·exp(-||b - μₐ||² / 2σₐ²)
```

- 第一项：外部场 h（知识锚点的吸引力）
- 第二项：信念交互 J（Ising 模型，信念之间的耦合）
- 第三项：**误解吸引子**（高斯势阱，每个误解是一个局部能量极小值）

**关键洞见**：学生被"困"在误解吸引子中，就像粒子被困在势阱里。正确的追问相当于给系统注入能量，帮助学生跨越壁垒。

### 2.3 认知动力学方程

```
db/dt = -γ·∇E(b) + η(t) + F(t)
```

- γ·∇E(b)：梯度下降力（自然趋向低能量态）
- η(t)：认知噪声（探索性思维）
- F(t)：追问驱动力（外部干预）

### 2.4 相变检测

定义认知序参数：
```
φ(t) = (1/N)·Σᵢ bᵢ(t)
```

认知磁化率（对扰动的敏感度）：
```
χ(t) = (1/T)·[⟨φ²⟩ - ⟨φ⟩²]
```

当 χ(t) 突然增大时，系统处于**临界点**——学生即将发生认知相变。这是追问的最佳时机。

### 2.5 能量壁垒与逃逸概率

从当前状态到正确理解的能量壁垒：
```
ΔE = max(saddle) - E(b_current)
```

逃逸概率（Arrhenius 公式）：
```
P_escape = exp(-ΔE / T)
```

### 2.6 最优追问力场

```
F_optimal = -γ·∇E(b) + λ·(b_correct - b)
```

即同时沿能量下降方向和指向正确理解的方向施加力。

## 四、自优化机制

### 第 1 轮：参数贝叶斯自适应

根据对话反馈调整超参数 γ（阻尼）、T（温度）。
- 追问效果差 → 降低阻尼（增加探索性）
- 相变过于频繁 → 降低温度
- 几乎不发生相变 → 增加温度

### 第 2 轮：吸引子自动发现

从累积对话数据中聚类，发现新的误解模式：
1. 收集学生"卡住"的状态（效果差、能量高）
2. DBSCAN 聚类
3. 与已有吸引子去重
4. 添加为新吸引子

### 第 3 轮：力场精细化

根据追问效果反馈调整力场权重：
- 好的追问方向 → 强化
- 坏的追问方向 → 削弱
- 探索权重逐渐衰减

## 六、质量指标

| 指标 | CCG (旧) | CPTE (新) |
|------|-----------|-----------|
| 冲突检测 | 规则 + LLM Prompt | 能量景观几何分析 |
| 追问时机 | 固定 15 秒 | 相变临界点动态检测 |
| 追问方向 | 随机/经验 | 最优力场 F_optimal |
| 可解释性 | 低（LLM 黑箱） | 高（能量/壁垒/路径可视化） |
| 自优化 | 无 | 3 轮贝叶斯自适应 |
| 响应时间 | 3-5 秒（2 次 LLM） | <1 秒本地计算 + 1 次 LLM |
| 技术门槛 | Prompt 工程 | 统计物理 + 随机微分方程 + 贝叶斯优化 |
