# 第一部分：项目概述

## 一、项目愿景

### 1.1 愿景

成为每个学习者身边"永不缺席的启明星"——一个从学科辅导到兴趣培养，坚持"不给答案，只给引导"的AI全能陪练助教。

### 1.2 核心定位

- **公开定位**：AI陪练助教——辅助教师、解放家长、赋能学生
- **实质定位**：具备追问引导能力的智能知识引擎

### 1.3 名称含义

- **星伴**：在思维的多元宇宙中，陪你穿梭于不同思考维度的导航星
- **启明**：启明星，天亮前最亮的星。每一次追问，都是在帮你照亮一个平行宇宙

### 1.4 核心原则

1. **永不直接给答案**：AI的第一反应永远是提问引导
2. **过程可见**：所有思考路径透明，可回溯
3. **先窄后宽**：从单一学科切入，验证后扩展
4. **多元平等**：没有"唯一正确的宇宙"，只有"适用于不同条件的宇宙"

### 1.5 最大卖点："可见的思考"

将学生解题时的内在思维过程，外化为一份可阅读、可回溯、可分享的《多元宇宙探索日志》。

# 第二部分：双算法引擎

## 一、CPTE：认知相变引擎

### 1.1 算法概述

**CPTE（Cognitive Phase Transition Engine）** 是一个基于物理学的算法，用于检测学生认知状态的相变点——即学生"一推就通"的临界时刻。

**核心思想**：将学生的认知状态建模为一个在能量景观中运动的粒子，当粒子到达鞍点附近时，就是最佳的追问时机。

### 1.2 核心概念

| 概念 | 物理类比 | 教学含义 |
|------|---------|---------|
| 认知状态 b(t) | 粒子位置 | 学生当前的信念向量 |
| 能量景观 E(b) | 势能面 | 信念的"错误程度" |
| 相变 | 相态转变 | 从"不懂"到"懂"的突变 |
| 序参数 φ(t) | 有序度 | 学生思维的清晰度 |
| 磁化率 χ(t) | 响应度 | 学生对引导的敏感度 |
| 噪声 η(t) | 热涨落 | 学生的随机探索 |

### 1.3 核心方程

**朗之万动力学方程**：
```
db/dt = -γ·∇E(b) + η(t) + F(t)
```

其中：
- `-γ·∇E(b)`：梯度下降力（自然趋向低能量态）
- `η(t)`：认知噪声（随机探索），⟨ηη⟩ = 2T·δ(t-t')
- `F(t)`：追问驱动力（外部干预）

### 1.4 能量景观模型

**多吸引子景观**：
```
E(b) = Σ αᵢ·exp(-||b - cᵢ||² / 2σᵢ²)
```

常见吸引子：
- **正确理解谷**：能量最低，稳定状态
- **常见错误谷**：局部极小值，需要外力逃逸
- **部分理解鞍**：不稳定平衡，一推就倒

### 1.5 相变检测

**检测信号**：

| 信号 | 公式 | 含义 |
|------|------|------|
| 序参数突变 | Δφ/Δt > threshold | 思维清晰度突变 |
| 磁化率峰值 | χ(t) → max | 对引导极度敏感 |
| 能量鞍点 | ∇E = 0, ∇²E < 0 | 临界不稳定态 |
| 信念旋转 | cos(b(t), b(t-1)) < 0 | 思路突变 |

## 二、CPPA：认知画像与个性化算法

### 2.1 算法概述

**CPPA（Cognitive Profile & Personalization Algorithm）** 是一个认知画像构建算法，用于分析学生的思维特点、学习习惯、惯性思维，并提供个性化的教学策略。

**核心思想**：通过贝叶斯推断构建15维认知画像，基于画像匹配最适合的教学方法。

### 2.2 15维认知画像

| 维度 | 说明 | 范围 |
|------|------|------|
| visual | 视觉型偏好 | 0-1 |
| verbal | 语言型偏好 | 0-1 |
| kinesthetic | 动手型偏好 | 0-1 |
| inductive | 归纳推理 | 0-1 |
| deductive | 演绎推理 | 0-1 |
| analogical | 类比推理 | 0-1 |
| forward | 正向思维 | 0-1 |
| backward | 逆向思维 | 0-1 |
| trial | 试错思维 | 0-1 |
| fast_jump | 跳跃思维 | 0-1 |
| rigorous | 严谨思维 | 0-1 |
| divergent | 发散思维 | 0-1 |
| abstract_reasoning | 抽象推理 | 0-1 |
| challenge_drive | 挑战偏好 | 0-1 |
| attention_span | 注意力持续 | 0-1 |

### 2.3 贝叶斯画像更新

**核心公式**：
```
P(θ|D) ∝ P(D|θ) × P(θ)
```

**简化实现**：
```python
new_value = old_value × (1-α) + evidence × α
```
其中 α = 0.3（平滑因子）

### 2.4 学生状态分类

| 状态 | 代号 | 特征 | 教学策略 |
|------|------|------|---------|
| 主动探索 | S1_exploring | 主动提问、尝试 | 引导式提问 |
| 局部卡壳 | S2_partial_stuck | 部分正确、犹豫 | 提示+提问 |
| 深度卡住 | S3_deep_stuck | 说"不会"、长时间沉默 | 类比教学 |
| 概念错误 | S4_concept_error | 明显错误、坚持己见 | 概念重建 |
| 情绪低落 | S5_frustrated | 负面情绪词汇 | 安抚降级 |

### 2.5 六种教学策略

| 策略 | 代号 | 适用场景 | 实现方式 |
|------|------|---------|---------|
| 引导式提问 | A_guided | 学生探索中 | 问题链引导 |
| 提示+提问 | B_hint | 局部卡壳 | 分级提示 |
| 类比教学 | C_analogy | 深度卡住 | 生活例子类比 |
| 概念重建 | D_concept_rebuild | 概念错误 | 纠正+重建 |
| 安抚降级 | E_comfort | 情绪低落 | 降低难度 |
| 突破惯性 | F_break_inertia | 思维惯性 | 引导新方法 |

### 2.6 惯性检测

**检测指标**：
```python
concentration = 1 - entropy/max_entropy  # 方法集中度
dominant_ratio = max_count / total       # 主导方法占比
efficiency_gap = 1 - current/best        # 效率差距

inertia_strength = 0.3×concentration + 0.3×dominant_ratio + 
                   0.25×inefficiency + 0.15×duration
```

**突破策略**：
- efficiency_shock：展示更高效方法
- gradual_expansion：逐步引入新方法
- awareness_boost：提高元认知意识

### 2.7 遗忘曲线（Ebbinghaus）

```python
C(t) = baseline + (mastery - baseline) × exp(-t / half_life)
```

其中：
- `C(t)`：t时刻的记忆强度
- `mastery`：学习后的掌握度
- `baseline`：基线记忆（永远不会忘记的部分）
- `half_life`：半衰期（与复习次数相关）

### 2.8 解法推荐

**三模式推荐**：

| 模式 | 目标 | 实现 |
|------|------|------|
| comfort | 用最擅长的方法 | 匹配度×0.7 + 历史成功率×0.3 |
| expand | 探索新方法 | 匹配度×0.3 + 成长潜力×0.7 |
| challenge | 适度挑战 | 匹配度×0.5 + 难度适配×0.5 |
